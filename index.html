업데이트 방법

모듈을 구매한 뒤에는 위 최신 펌웨어와 모듈 버전(모듈 첫 화면 › 펌웨어 정보)을 비교해 보고, 다르면 업데이트해 주세요. 업데이트로 더해진 기능을 쓸 수 있습니다.

  1. 펌웨어 파일 받기

    위 펌웨어 받기를 누릅니다. 아이폰은 파일 앱 › 다운로드, 안드로이드는 내 파일 › 다운로드에 저장됩니다. 파일 이름은 바꾸지 않아도 됩니다.

  2. 차량 준비

    차량 전원을 켜고 기어를 P단에 둡니다. 업데이트가 끝날 때까지 P단을 유지하세요.

  3. 모듈 Wi-Fi 연결

    휴대폰 Wi-Fi 목록에서 TuFModule- 뒤에 차대번호(VIN) 끝 5자리가 붙은 이름을 고릅니다. 비밀번호를 바꾸지 않았다면 차대번호 끝 8자리입니다.

  4. 모듈 화면 열기

    Wi-Fi에 연결하면 모듈 화면이 Wi-Fi 연결 화면으로 저절로 열립니다. 열리지 않으면 Safari나 Chrome 주소창에 4.3.2.1을 입력하세요. 첫 화면에서 메뉴 › 펌웨어 업데이트로 들어갑니다.

  5. 파일 고르고 시작

    펌웨어 파일 선택에서 받은 파일을 고르고 업데이트 시작을 누른 뒤, 확인 창에서 시작을 누릅니다. 약 1분 걸립니다. 중간에 모듈이 다시 시작하면서 Wi-Fi가 잠시 끊기니, 휴대폰을 모듈 Wi-Fi에 다시 연결해 주세요. 진행 중에는 차량 전원을 끄거나 페이지를 닫지 마세요.

  6. 버전 확인

    휴대폰이 모듈 Wi-Fi에 다시 연결되면 결과가 나옵니다. 첫 화면 › 펌웨어 정보의 메인 · 서브 버전이 위 최신 펌웨어와 같으면 끝입니다. 모듈 Wi-Fi로는 인터넷이 되지 않으니, 끝나면 휴대폰 Wi-Fi를 원래 쓰던 네트워크로 바꿔 주세요.

안 될 때

파일 선택 버튼을 눌러도 파일을 고를 수 없어요

안드로이드는 Wi-Fi 연결 화면에서 파일을 고를 수 없습니다. 모듈 펌웨어 업데이트 화면 아래 파일 선택이 안 되나요? › 열기를 누르거나, Wi-Fi 연결 화면을 닫고 Chrome 주소창에 4.3.2.1을 입력해 다시 들어가세요.

“P단에서 업데이트해 주세요”가 나와요

차량 전원을 켜고(브레이크를 밟거나 화면을 켜서) 기어를 P단에 둔 뒤 다시 확인을 누르세요.

“서명된 TuFModule 펌웨어 파일이 아닙니다” · “파일이 손상되었거나 올바른 펌웨어 파일이 아닙니다”가 나와요

이 페이지에서 받은 파일만 올릴 수 있습니다. 파일을 지우고 다시 받아 올려 주세요. 업데이트하지 못한 경우 모듈은 원래 펌웨어 그대로 동작합니다.

업데이트 중에 연결이 끊겼어요

연결이 끊겨도 모듈은 업데이트를 끝까지 진행합니다. 1 ~ 2분 뒤 모듈 Wi-Fi에 다시 연결하면 첫 화면에 결과가 나옵니다. 진행 중에는 모듈 LED가 차례로 켜지고, 끝나면 LED 4개가 함께 깜빡입니다. 천천히 3번이면 완료, 빠르게 깜빡이면 실패입니다.

모듈 Wi-Fi 비밀번호를 모르겠어요

바꾸지 않았다면 차대번호(VIN) 끝 8자리입니다. 차대번호는 앞유리 왼쪽 아래나 차량 화면 › 소프트웨어 › 추가 차량 정보에서 볼 수 있습니다. 바꾼 비밀번호를 잊었다면 모듈을 초기화해야 합니다. 방법은 사용설명서 29쪽 ‘재시작과 초기화’를 보세요.
