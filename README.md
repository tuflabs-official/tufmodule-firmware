# TuFModule 펌웨어

TuFLabs **TuFModule** 공식 펌웨어 배포 저장소입니다.

- **최신 펌웨어 받기 · 업데이트 방법:** https://tuflabs-official.github.io/tufmodule-firmware/
- 모든 버전: [Releases](https://github.com/tuflabs-official/tufmodule-firmware/releases)

TuFModule에는 TuFLabs가 서명한 펌웨어 파일(`TuFModule_PKG_….bin`)만 설치됩니다. 이 저장소에서 받은 파일만 사용해 주세요.
